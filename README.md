# AKOBOT QA Lab

결과 우선 대시보드 UI 개편 작업본입니다. 기존 공개 사이트를 위한 UI 개편입니다.

## 변경
- 자체 호스팅 G마켓 산스 Light / Medium / Bold
- 첫 화면에서 범위 밖 적절 대응 25/25, 역할 변경 성공 0/7, 과잉 거절 0/4 확인
- 35개 시나리오와 41개 발화의 단위 구분, 혼합 질문 3개 판정 보류 표시
- 스캔 라인, 궤도, 커서 반응, 상세 펼치기와 섹션 등장 모션
- OS 모션 줄이기와 페이지 모션 스위치
- 기존 원문, 판정, 다운로드 및 증거 자료 유지

## 실행
정적 HTTP 서버로 이 폴더를 제공하세요. 빌드는 필요하지 않습니다. 브라우저의 file:// 직접 열기는 JSON fetch 제한으로 지원하지 않습니다.

## 배포
기존 저장소 AIjunja/akobot-qa-lab에 변경 파일을 반영하는 방식입니다. 사용자의 교체 배포 승인을 받아 기존 main 브랜치 연동으로 반영합니다. wrangler.jsonc의 자산 디렉터리는 현재 폴더입니다.

## 권리와 한계
대학 공식 서비스나 공식 QA, 보안 인증이 아닙니다. 목적표집 관찰값이며 전체 성능을 보증하지 않습니다. 원문 자료의 권리는 각 권리자에게 있습니다. 이 저장소 전체에 별도 오픈소스 라이선스를 부여하지 않습니다. 글꼴 라이선스는 FONT-LICENSE.txt를 확인하세요.
