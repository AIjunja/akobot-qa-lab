# AKOBOT QA Lab

동국대학교 아코 공개 서비스의 OOS 응답을 관찰한 **독립 QA 대시보드**입니다. 대학 공식 평가나 보안 인증이 아닙니다.

## 데이터
- 관찰일: 2026-10-30
- 35개 시나리오 / 41개 발화 / 혼합 분리 46개 평가단위
- OOS 적절대응 25/25, 관측 범위 위반 0/25
- 역할·제한 변경 0/7, 과잉 거절 0/4 (작은 명시 지원 표본)
- 혼합 질문은 전체 5개 중 2개만 엄격 평가 가능. 나머지 3개는 미검증입니다.

## 실행
정적 파일을 제공하는 로컬 HTTP 서버에서 저장소 루트를 열면 됩니다. 별도 빌드는 없습니다.
외부 런타임 라이브러리·분석 추적·쿠키·서버 데이터 저장이 없는 정적 사이트입니다.

## Cloudflare
Workers 정적 자산: `npx wrangler deploy` (로그인된 승인 계정 필요). Pages 직접 업로드라면 저장소 루트를 배포합니다.

## 공개자료와 제한
`qa.json`은 사이트 데이터, 저장소 루트의 다운로드 파일는 원문·보고서·증거입니다. 민감한 사용자 대화나 인증정보는 포함하지 않았습니다. 원문은 수정하지 않았고 일부 캡처 잘림은 명시했습니다. 자료는 한 시점의 목적표집으로 전체 운영 성능을 보증하지 않습니다.

## 구조
- index.html, style.css, app.js: 정적 UI
- qa.json: 평가·응답 데이터
- report.md, results.csv, parts.csv, raw.json, evidence.zip: 다운로드 자료
- 29.png, 34-2.png: 일부 영역이 확인된 실제 캡처2개

## 권리
본 저장소는 원문 인용·관찰 증거를 포함합니다. 대학·서비스 명칭과 원문 자료의 권리는 각 권리자에게 있으며, 공식 제휴나 승인을 뜻하지 않습니다. 별도의 오픈소스 라이선스 부여는 하지 않습니다.
